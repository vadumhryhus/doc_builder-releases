# Doc Builder: збірки й оновлення

Тут лежать лише готові збірки програми Doc Builder (RecruiterUA) і маніфести, з яких встановлені програми дізнаються про нові версії. Код програми зберігається окремо, у приватному репозиторії.

- `appcast-macos.xml`, `appcast-windows.xml` — маніфести оновлень. Їх оновлює автоматична збірка, вручну не редагуйте.
- **Releases** — архів для macOS і інсталятор для Windows кожної версії.

Програма без пароля не відкривається. Усі оновлення підписані ключем Ed25519, тож встановлена програма відкине підроблений файл.
